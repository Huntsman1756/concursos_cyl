# Avisos de terceros

Las dependencias de ejecución y desarrollo se instalan desde npm conforme a
`package-lock.json`. Sus avisos y licencias son propiedad de sus autores. El
chequeo reproducible se ejecuta con `npm run licenses:check`.

Dependencias directas principales:

| Paquete | Licencia |
| --- | --- |
| React, React DOM, React Router DOM | MIT |
| Zod, MiniSearch, Vite, TypeScript | MIT |
| `@radix-ui/*` | MIT |
| `@observablehq/plot` | ISC |
| `lucide-react` | ISC |
| `sanitize-html` | MIT |
| Vitest, Playwright, axe-core, ESLint, Prettier | MIT o licencias permisivas declaradas por cada paquete |

El proyecto no incorpora código de marca, logotipos ni librerías de SBB. Los
principios de diseño de SBB y las skills/agentes de desarrollo son referencias
de trabajo, no dependencias runtime distribuidas por esta aplicación.
