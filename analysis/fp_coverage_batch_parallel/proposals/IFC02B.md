# Propuesta de correspondencias IFC02B → CNO-11

## Ficha de origen

- **Fuente:** TodoFP, Ministerio de Educación, Formación Profesional y Deportes.
- **URL:** https://www.todofp.es/que-estudiar/familias-profesionales/informatica-comunicaciones/informatica-oficina.html
- **Título:** Título Profesional Básico en Informática de Oficina.
- **Salida profesional (cita textual de TodoFP):** `ayudante de montador de sistemas microinformáticos`

## Candidatos propuestos

### 1. Código CNO-11: 7533

| Campo                            | Valor                                                                                                                                                                                                                                                                                                                    |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **occupationId**                 | `occupation:cno11:7533`                                                                                                                                                                                                                                                                                                  |
| **Código**                       | 7533                                                                                                                                                                                                                                                                                                                     |
| **Etiqueta exacta del catálogo** | Instaladores y reparadores en tecnologías de la información y las comunicaciones                                                                                                                                                                                                                                         |
| **Cita textual de TodoFP**       | `ayudante de montador de sistemas microinformáticos`                                                                                                                                                                                                                                                                     |
| **Justificación**                | La palabra "montador" se refiere a la instalación física de sistemas microinformáticos (ensamblaje de equipos, cableado, puesta en marcha), que es el núcleo del group 7533 (ICT installers and repairers). El rol de "ayudante" implica un nivel básico de estas tareas, coherente con la formación profesional básica. |
| **Nivel de confianza**           | Alto                                                                                                                                                                                                                                                                                                                     |

### 2. Código CNO-11: 3812

| Campo                            | Valor                                                                                                                                                                                                                                                                                                                                   |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **occupationId**                 | `occupation:cno11:3812`                                                                                                                                                                                                                                                                                                                 |
| **Código**                       | 3812                                                                                                                                                                                                                                                                                                                                    |
| **Etiqueta exacta del catálogo** | Técnicos en asistencia al usuario de tecnologías de la información                                                                                                                                                                                                                                                                      |
| **Cita textual de TodoFP**       | `ayudante de montador de sistemas microinformáticos`                                                                                                                                                                                                                                                                                    |
| **Justificación**                | La especialidad pertenece a la familia de Informática y Comunicaciones y, en un contexto de oficina, el perfil puede evolucionar hacia soporte técnico a usuarios. "Ayudante" se aproxima a funciones de asistencia. Coincide con el group 3812 (IT user support technicians), aunque no es la correspondencia principal de "montador". |
| **Nivel de confianza**           | Medio                                                                                                                                                                                                                                                                                                                                   |

### 3. Código CNO-11: 3811

| Campo | Valor |
|-------|-------|-------|
| **occupationId** | `occupation:cno11:3811` |
| **Código** | 3811 |
| **Etiqueta exacta del catálogo** | Técnicos en operación de sistemas informáticos |
| **Cita textual de TodoFP** | `ayudante de montador de sistemas microinformáticos` |
| **Justificación** | El título "Informática de Oficina" incluye operar sistemas informáticos en entornos de oficina. "Montador" puede interpretarse como preparación/operación del entorno informático. El group 3811 (IT systems operators) capta el nivel básico de manejo de sistemas que correspondería a esta especialidad FP básica. |
| **Nivel de confianza** | Medio |

### 4. Código CNO-11: 8202

| Campo                            | Valor                                                                                                                                                                                                                                                                                                             |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **occupationId**                 | `occupation:cno11:8202`                                                                                                                                                                                                                                                                                           |

| **Etiqueta exacta del catálogo** | Ensambladores de equipos eléctricos y electrónicos                                                                                                                                                                                                                                                                |
| **Cita textual de TodoFP**       | `ayudante de montador de sistemas microinformáticos`                                                                                                                                                                                                                                                              |
