## Function area 1: Radioterapia

### Literal sourceQuotes

> "Técnica / técnico especialista en radioterapia."  
> _(SAN09S.txt, quote 3)_

> "Técnica / técnico superior en radioterapia."  
> _(SAN09S.txt, quote 4)_

### CNO-11 candidate

| Field                  | Value                                                                                                  |
| ---------------------- | ------------------------------------------------------------------------------------------------------ |
| **occupationId**       | `occupation:cno11:5629`                                                                                |
| **classificationCode** | 5629                                                                                                   |
| **preferredLabel**     | Trabajadores de los cuidados a las personas en servicios de salud no clasificados bajo otros epígrafes |
| **reviewStatus**       | approved                                                                                               |

**Justification:**  
El técnico especialista/superior en radioterapia realiza la administración de tratamientos de radioterapia, posicionamiento e inmovilización del paciente, verificación de equipos y cuidados directos dentro del servicio de oncología radioterápica. CNO-11 5629 es la categoría residual para trabajadores de cuidados de salud no clasificados en otros epígrafes; en la práctica absorbe a los técnicos superiores en radioterapia y dosimetría que ejecutan funciones asistenciales directas en servicios hospitalarios de radioterapia.

**Riesgo:** Categoría residual que puede confluir con otros roles de apoyo sanitario (auxiliares de enfermería, técnicos de farmacia). No refleja el nivel de "técnico superior" específicamente, sino que agrupa a todo trabajador de cuidados de salud no clasificado.

## Function area 2: Dosimetría

### Literal sourceQuotes

No existe una sourceQuote independiente para "dosimetría". La función está cubierta por el título oficial del programa:

> "Técnico Superior en Radioterapia y Dosimetría"  
> _(SAN09S.txt, line 7)_

### CNO-11 candidate

| Field                  | Value                                                                                                  |
| ---------------------- | ------------------------------------------------------------------------------------------------------ |
| **occupationId**       | `occupation:cno11:5629`                                                                                |
| **classificationCode** | 5629                                                                                                   |
| **preferredLabel**     | Trabajadores de los cuidados a las personas en servicios de salud no clasificados bajo otros epígrafes |
| **reviewStatus**       | approved                                                                                               |

**Justificación:**  
La dosimetría (cálculo de dosis, planificación de tratamiento, control de calidad dosimétrico) es ejercida por el mismo profesional que la radioterapia. El título oficial del programa integra ambas funciones en un solo perfil. El candidato es el mismo que para radioterapia (5629).

**Riesgo:** Ausencia de sourceQuote dedicada. La función dosimétrica comparte candidato con radioterapia; no existe un código CNO-11 específico para dosimetristas. Si se requiriese un candidato separado, no hay ninguno disponible en el catálogo approved.

## Function area 3: Protección radiológica

### Literal sourceQuote

> "Personal auxiliar de los servicios de protección radiológica."  
> _(SAN09S.txt, quote 2)_

### CNO-11 candidate

| Field                  | Value                                                                                   |
| ---------------------- | --------------------------------------------------------------------------------------- |
| **occupationId**       | `occupation:cno11:3129`                                                                 |
| **classificationCode** | 3129                                                                                    |
| **preferredLabel**     | Otros técnicos de las ciencias físicas, químicas, medioambientales y de las ingenierías |
| **reviewStatus**       | approved                                                                                |

**Justificación:**  
El personal auxiliar de protección radiológica realiza vigilancia de radiaciones, mediciones de tasa de dosis, control de contaminación, dosimetría personal y verificaciones de blindaje. Estas son funciones técnicas propias de las ciencias físicas aplicadas a la salud (física radiológica, protección radiológica). CNO-11 3129 es la categoría residual para técnicos de ciencias físicas no clasificados en otros epígrafes, y constituye la correspondencia funcional directa más próxima dentro del catálogo approved.

**Riesgo:** Categoría residual que puede absorber técnicos de otras disciplinas físicas, químicas o medioambientales sin relación con la protección radiológica. No existe un código CNO-11 específico para "personal de protección radiológica".

## Function area 4: Comercial de equipos de radioelectrología médica

### Literal sourceQuote

> "Delegada / delegado comercial de equipos de radioelectrología médica"  
> _(SAN09S.txt, quote 1)_

### CNO-11 candidate (primario)

| Field                  | Value                                                        |
| ---------------------- | ------------------------------------------------------------ |
| **occupationId**       | `occupation:cno11:2640`                                      |
| **classificationCode** | 2640                                                         |
| **preferredLabel**     | Profesionales de ventas técnicas y médicas (excepto las TIC) |
| **reviewStatus**       | approved                                                     |

**Justificación:**  
El delegado comercial de equipos de radioelectrología médica vende equipamiento médico especializado que requiere conocimiento técnico-científico y médico del producto. CNO-11 2640 captura exactamente a los profesionales que realizan ventas de productos técnicos y médicos (con exclusión de TIC), lo que constituye correspondencia funcional directa.

**Riesgo:** El nivel CNO-11 2640 es "profesionales" (gran grupo 2, titulación universitaria), mientras que el título de FP es de Técnico Superior (gran grupo 3). Puede existir desajuste de nivel si el rol se desempeña sin titulación universitaria.

### CNO-11 candidate (secundario)

| Field                  | Value                                |
| ---------------------- | ------------------------------------ |
| **occupationId**       | `occupation:cno11:3510`              |
| **classificationCode** | 3510                                 |
| **preferredLabel**     | Agentes y representantes comerciales |
| **reviewStatus**       | approved                             |

**Justificación:**  
"Delegado comercial" es sinónimo de agente o representante comercial. CNO-11 3510 cubre agentes y representantes comerciales en términos generales.

**Riesgo:** Categoría genérica que no refleja la especialización técnica y médica del equipamiento de radioelectrología. Se recomienda como alternativa solo si 2640 se considera sobrecualificado.
