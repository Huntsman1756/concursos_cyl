# Archivo del protocolo de preparación

Este documento conserva el procedimiento preparado el 8 de septiembre de 2026 como referencia histórica. No es una lista de tareas pendientes para presentar la candidatura.

1. Ejecutar `npm run pilot:preflight` y conservar el resultado local: versión pública, instantánea y hashes del protocolo y del guion.
2. Comprobar las cinco tareas del [guion](anonymous-task-script.md), el consentimiento y la disponibilidad de 5–10 participantes adultos, incluyendo ambos roles definidos. No reclutar ni contactar personas automáticamente.
3. Usar los mismos textos sin orientar a la respuesta. Agregar solo los conteos y códigos previstos; no grabar, conservar citas ni crear filas identificables por sesión.
4. Al finalizar, validar el agregado con `npm run pilot:anonymous:validate -- --require-complete`. No producir un archivo de resultados rellenado de ejemplo como si fueran observaciones reales.
5. Priorizar barreras que impidan terminar una tarea, interpretar una relación o localizar la fuente; corregirlas y repetir las tareas afectadas.

Si cambia el producto durante las sesiones, detener el piloto y registrar un nuevo grupo de observaciones para esa versión; no mezclar resultados entre versiones. El agregado acredita comprensión exploratoria, no representatividad ni impacto laboral.
