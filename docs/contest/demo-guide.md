# Demostración de SALIDA CyL (2 minutos)

Usar la versión pública final y comprobar sus fechas antes de grabar. No mostrar cuentas, formularios personales ni paneles de administración.

1. **0:00–0:20 — Problema.** «Para elegir una FP hay que consultar estudios, profesiones, centros y ofertas en sitios distintos. SALIDA reúne esas consultas y permite comprobar sus fuentes».
2. **0:20–0:50 — Recorrido.** En Inicio, buscar Cuidados Auxiliares de Enfermería, abrir SAN21 y mostrar salidas relacionadas. «Puedo explorar las ocupaciones documentadas para este ciclo y abrir el perfil oficial que las respalda».
3. **0:50–1:15 — Siguiente paso.** Mostrar ofertas relacionadas y su fecha; abrir el listado de centros. «Estas ofertas pertenecen a una descarga fechada. Antes de solicitar una, compruebo su vigencia en la fuente. También puedo localizar dónde estudiar».
4. **1:15–1:35 — Límite.** Abrir Programadores informáticos, CNO 3820. «Que no aparezca una oferta vinculada no significa que no existan oportunidades. La aplicación conserva las formaciones revisadas y explica la ausencia».
5. **1:35–2:00 — Reutilización.** Abrir Datos abiertos y mostrar JSON/CSV. «Las relaciones se devuelven como datos reutilizables con procedencia. En esta versión, 130 de 187 claves de programa tienen relaciones revisadas; 128 de 1.032 ofertas están vinculadas. Son cifras de cobertura, no inserción laboral medida».

Cerrar mostrando el enlace a la candidatura del X Concurso de Datos Abiertos y la memoria PDF. Este guion acompaña la demo; no añade palabras a la memoria de solicitud.
