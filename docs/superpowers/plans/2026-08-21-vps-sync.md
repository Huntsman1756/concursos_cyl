# VPS Synchronization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restore secure macOS access and deploy the exact reviewed Git commit to the canonical VPS through the existing atomic release contract.

**Architecture:** A dedicated local-only ED25519 key authorizes the Mac. A POSIX script mirrors the PowerShell build, upload, atomic activation, retention, and live verification behavior without storing credentials in the repository.

**Tech Stack:** POSIX shell, OpenSSH, tar, Node.js 24, Caddy, Vitest contract tests.

**Spec:** `docs/superpowers/specs/2026-08-21-parallel-continuation-wave-design.md`

## Global Constraints

- Never print, commit, copy, or delegate the private SSH key.
- Do not change VPS authorization until the user executes the public-key command from an already authorized host.
- Require clean Git state and exact 40-character HEAD SHA before packaging.
- Retain five releases and switch `current` atomically.
- Prefix repository shell commands with `rtk`.
