Cómo se construyen los derivados

A partir de las fuentes oficiales (TodoFP y BOE para los títulos, catálogo CNO-11 del SEPE para ocupaciones, ECYL para centros y ofertas) se normalizan los catálogos, se revisan las relaciones y se publica únicamente lo aprobado, con la evidencia conservada. El proceso completo está explicado en la metodología.
