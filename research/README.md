# Investigación previa

No forma parte de la memoria ni de los adjuntos generales exigidos para el concurso. Para evaluar la candidatura vigente, consultar la [memoria](../docs/contest/jury-memo.md), el [inventario de fuentes](../docs/contest/source-ledger.md) y los [límites](../docs/contest/limitations.md).
